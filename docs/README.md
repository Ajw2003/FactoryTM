# FactoryTM docs

FactoryTM is a Unity game about running a factory on an alien world and defending it from nightly raids.
These pages explain how it is built and where the work stands.

| Folder | What is in it |
|---|---|
| `1-landing` | Start here: what the project is and where everything is |
| `2-roadmap` | What "finished" means, in nine milestones |
| `3-state` | How far along each milestone really is |
| `4-systems` | How the important parts of the code work and what breaks them |
| `5-today` | What is being worked on today |
| `6-decisions` | The log of why things were decided |
| `plans` | Plans for specific pieces of work |
| `archive` | Old notes that are no longer true, kept for reference |
| `generated` | Reports made by tools |

The full index is in [1-landing/README.md](1-landing/README.md).
